## Atividade 1 - Comparação entre Prompts ##
# nessa Atividade a Professora passou a importância de utilizar a I.A com Prompts mais Alinhados de Maneira estratégicas e mostrando outras maneiras de criar um prompt #
Prompt Genêrico

Explique o que é I.A Generativa


Prompt RTF

Role : Você é um estudante de Engenharia de Prompt

Task : explique o que é Uma Inteligência Artificial Generativa

Format : Responda em uma lista em 5 tópicos 

Prompt CRAFT

Contexto: Uma pequena empresa quer Aprender a Usar a Inteligência Artificial de Forma estratégica 

Role: Você é especialista em Engenharia de Prompt

Action: Explique estratégias de Como elaborar um prompt de maneira eficaz para a I.A

Format: Apresente 5 estratégias em lista. formule em Markdown

Target: Pessoas Sem Contato Com Inteligência Artificial

Prompt COSTAR

Contexto: Uma Pequena Empresa Quer Investir para que os jovens aprendam a usar a I.A de Maneira Eficaz

Objetivo: Criar estratégias para que os jovens aprendam e se desenvolvam com o avanço da Tecnologia

Estilo: Didático e em uma linguagem mais próxima para os jovens

Tom: Profissional.

Audiência: Iniciantes na área de Tecnologia 

Resposta: Liste 5 estratégias e explique cada uma e como posso utilizar ela na sala de aula 


# Atividade 2 – Identificação de estrutura #
# Nessa o Própostito é saber qual tipo de prompt está sendo utilizado ##


Prompt A

```
Explique o que é computação em nuvem. # Esse aqui é um prompt Generico / Prompt Simples 
```

Prompt B

```
Role: Você é professor de tecnologia.

Task: Explique computação em nuvem.  # Prompt RTF

Format: Responda em 3 tópicos
```

Prompt C

```
Contexto: Uma empresa quer migrar seus sistemas para a nuvem.

Role: Especialista em cloud computing.

Action: Explique vantagens da computação em nuvem. # Prompt Craft

Format: Lista de 5 pontos.

Target: Gestores de TI iniciantes.
```


Prompt D

```
Contexto: Uma empresa quer migrar para a nuvem.

Objetivo: Explicar benefícios da computação em nuvem.

Estilo: Educativo.                   # Prompt COSTAR

Tom: Profissional.

Audiência: Gestores de TI.

Formato da resposta: 5 tópicos explicados.
```
